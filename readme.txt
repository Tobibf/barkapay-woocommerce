Une passerelle de paiement WooCommerce intégrant BarkaPay pour accepter des paiements en toute sécurité.

== Description ==

BarkaPay pour WooCommerce est une extension qui permet aux boutiques en ligne d'accepter des paiements via la plateforme BarkaPay. En intégrant cette passerelle de paiement, vous offrez à vos clients une méthode de paiement sécurisée et rapide directement sur votre site WooCommerce.

**Fonctionnalités principales :**

- Intégration transparente avec WooCommerce.
- Acceptation des paiements mobiles via BarkaPay.
- Personnalisation des pages de paiement.
- Notifications en temps réel pour les transactions réussies.
- Support multidevise.

== Installation ==

1. Téléchargez le plugin depuis le répertoire officiel ou depuis votre compte BarkaPay.
2. Accédez à votre tableau de bord WordPress, puis allez dans "Extensions" > "Ajouter".
3. Cliquez sur "Téléverser une extension" et sélectionnez le fichier ZIP du plugin.
4. Activez le plugin via le menu "Extensions" de WordPress.
5. Configurez le plugin en accédant à "WooCommerce" > "Réglages" > "Paiements" > "BarkaPay" et renseignez vos identifiants API.

== FAQ ==

= Quels sont les prérequis pour utiliser ce plugin ? =

Vous devez avoir une boutique WooCommerce fonctionnelle et un compte marchand actif chez BarkaPay.

= Comment obtenir mes identifiants API BarkaPay ? =

Connectez-vous à votre compte BarkaPay et accédez à la section "API" pour générer vos clés.

= Ce plugin est-il compatible avec les autres extensions WooCommerce ? =

Oui, BarkaPay pour WooCommerce est conçu pour être compatible avec la majorité des extensions WooCommerce standards.
